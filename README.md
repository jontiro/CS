Apuntes sobre algoritmos, estructuras de datos y análisis de complejidad.

### [Instalación](./Instalacion)
Guías de instalación de programas, herramientas y configuración de entornos de desarrollo.

### [Consejos](./Consejos)
Tips, trucos y mejores prácticas de programación.

### [Recursos](./Recursos)
Enlaces, referencias y materiales útiles para el aprendizaje.
