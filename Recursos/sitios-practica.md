# Sitios Web para Practicar Programación

Lista de plataformas para practicar coding y resolver problemas de algoritmos.

## Plataformas de Coding Challenges

### LeetCode
- **URL**: https://leetcode.com
- **Nivel**: Principiante a Avanzado
- **Idiomas**: Múltiples lenguajes de programación
- **Descripción**: Excelente para preparación de entrevistas técnicas. Tiene más de 2000 problemas clasificados por dificultad y tema.
- **Características**:
  - Problemas reales de entrevistas de empresas FAANG
  - Contests semanales
  - Sistema de discusión para cada problema
  - Versión gratuita y premium

### HackerRank
- **URL**: https://www.hackerrank.com
- **Nivel**: Principiante a Avanzado
- **Descripción**: Plataforma con retos de programación, bases de datos, matemáticas y más.
- **Características**:
  - Certificaciones en diversos lenguajes
  - Preparación para entrevistas
  - Competiciones
  - Retos de empresas

### CodeWars
- **URL**: https://www.codewars.com
- **Nivel**: Principiante a Avanzado
- **Descripción**: Aprende programación resolviendo "katas" (desafíos).
- **Características**:
  - Sistema de ranking por niveles (kyu)
  - Comunidad activa
  - Múltiples lenguajes
  - Aprendizaje gamificado

### Codeforces
- **URL**: https://codeforces.com
- **Nivel**: Intermedio a Avanzado
- **Descripción**: Plataforma competitiva de programación con contests regulares.
- **Características**:
  - Contests cada semana
  - Sistema de rating
  - Problemas de programación competitiva
  - Comunidad muy activa

## Plataformas de Aprendizaje Interactivo

### freeCodeCamp
- **URL**: https://www.freecodecamp.org
- **Nivel**: Principiante a Intermedio
- **Descripción**: Curriculum completo de desarrollo web gratuito.
- **Características**:
  - Certificaciones gratuitas
  - Proyectos prácticos
  - HTML, CSS, JavaScript, React, Node.js, etc.
  - Comunidad grande y activa

### Exercism
- **URL**: https://exercism.org
- **Nivel**: Principiante a Intermedio
- **Descripción**: Plataforma gratuita con mentoring incluido.
- **Características**:
  - Más de 50 lenguajes de programación
  - Mentoring gratuito
  - Ejercicios progresivos
  - Totalmente gratis

### Codingame
- **URL**: https://www.codingame.com
- **Nivel**: Principiante a Avanzado
- **Descripción**: Aprende programación jugando.
- **Características**:
  - Desafíos visuales e interactivos
  - Competiciones
  - Soporte para muchos lenguajes
  - Divertido y educativo

## Sitios Especializados

### Project Euler
- **URL**: https://projecteuler.net
- **Nivel**: Intermedio a Avanzado
- **Descripción**: Problemas matemáticos que requieren programación.
- **Características**:
  - Énfasis en matemáticas
  - Más de 700 problemas
  - Cualquier lenguaje de programación

### AtCoder
- **URL**: https://atcoder.jp
- **Nivel**: Principiante a Avanzado
- **Descripción**: Plataforma japonesa de programación competitiva.
- **Características**:
  - Contests regulares
  - Problemas bien diseñados
  - Disponible en inglés

## Recomendaciones

### Para Principiantes
1. freeCodeCamp - Aprender fundamentos
2. Exercism - Practicar con mentoring
3. HackerRank - Primeros desafíos

### Para Entrevistas
1. LeetCode - Principal recurso
2. HackerRank - Práctica adicional
3. AlgoExpert (https://www.algoexpert.io - pago) - Explicaciones detalladas

### Para Programación Competitiva
1. Codeforces - Contests regulares
2. AtCoder - Problemas de calidad
3. CodeChef - Otra opción popular

## Consejos

- Empieza con problemas fáciles y progresa gradualmente
- Lee las soluciones de otros después de resolver un problema
- Participa en contests para medir tu progreso
- No te desanimes si un problema parece difícil al principio
- La práctica constante es clave
